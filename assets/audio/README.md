# Audio

Esta carpeta está vacía a propósito: todos los efectos de sonido del juego se
sintetizan en tiempo real con la Web Audio API (ver `js/ui/audio.js`). Así el
juego no depende de archivos externos y funciona sin conexión.

Si en el futuro se añaden archivos de audio, deben ir aquí y registrarse en
`ASSET_CREDITS.md` con su autor, URL y licencia.
